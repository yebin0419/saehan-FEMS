EMS JSON 데이터 추출 방법 (즐겨찾기 스크립트)

사내 EMS 시스템 화면에서 아래 즐겨찾기(북마크릿)를 실행하면, 분석 기간(07:00 ~ 익일 07:00) 전류 데이터가 JSON으로 자동 저장됩니다. 아래 3단계를 따라주세요.

1. 즐겨찾기(북마크) 생성

  • 사용 중인 웹 브라우저(Chrome, Edge 등)에서 새 북마크/즐겨찾기를 생성합니다.
  • URL(웹주소) 입력 칸에 웹 주소 대신 아래 검은색 상자 안의 JavaScript 코드를 그대로 복사해 붙여넣고 저장합니다.
  • 예: javascript:(function(){ ... })(); 형태의 코드

2. EMS 웹페이지 접속 및 스크립트 실행

  • 데이터 추출 대상인 사내 EMS 조회 화면에 접속합니다.
  • 조회 기준 시간(07:00 ~ 익일 07:00)을 확인한 뒤, 1단계에서 만들어둔 즐겨찾기를 클릭합니다.
  • 웹페이지 내부 데이터가 자바스크립트에 의해 파싱(Parsing)된 후, JSON 파일이 자동으로 다운로드됩니다.

3. 분석 페이지에 업로드

  • 다운로드된 JSON 파일을 이 분석기 페이지의 파일 업로드 영역으로 드래그 앤 드롭하거나 선택하여 업로드합니다.
